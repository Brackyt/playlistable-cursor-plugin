# Playlistable

Make playlists on Spotify or Apple Music from Cursor.

Install the plugin, connect the account you already use on [playlistable.io](https://playlistable.io), then ask for a playlist. It lands in that service.

## Two ways to make a playlist

**You pick the songs.** Search, then save. Free. Playlistable is just the bridge into Spotify or Apple Music.

**Playlistable picks.** You give a mood. It uses listening history. That's the better playlist, and it's paid on playlistable.io (one free teaser).

## What you can do

- Save a playlist from songs you already chose
- Generate a playlist from a mood (paid / teaser)
- Search songs and artists
- Edit or delete playlists you made

## Install

In Cursor, open the Marketplace and install **Playlistable**. Same plugin in Grok Bot under Settings → Plugins.

When it asks, sign in with Spotify or Apple Music.
